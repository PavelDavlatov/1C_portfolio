## 2. Подстрока максимальной длины

Задача: 
Дана строка. Найти длину максимальной подстроки без повторов.

Пример:
- Вход: "abcabcb" → Результат: 3 (подстрока "abc")
- Вход: "bbbb" → Результат: 1 (подстрока "b")

Решение:

&НаКлиенте
Процедура Старт(Команда)
    ПроверитьЗадачу2();
КонецПроцедуры

&НаСервере
Процедура ПроверитьЗадачу2()
    Результат1 = МаксимальнаяПодстрока("abcabcbb");
    Результат2 = МаксимальнаяПодстрока("bbbbb");
    Результат3 = МаксимальнаяПодстрока("pwwkew");
    
    Сообщить("abcabcbb -> " + Результат1);
    Сообщить("bbbbb -> " + Результат2);
    Сообщить("pwwkew -> " + Результат3);
КонецПроцедуры

&НаСервереБезКонтекста
Функция МаксимальнаяПодстрока(Стр)
    МаксДлина = 0;
    Начало = 0;
    Позиции = Новый Соответствие;
    
    Для Инд = 1 По СтрДлина(Стр) Цикл
        Символ = Сред(Стр, Инд, 1);
        Если Позиции[Символ] <> Неопределено И Позиции[Символ] >= Начало Тогда
            Начало = Позиции[Символ] + 1;
        КонецЕсли;
        Позиции.Вставить(Символ, Инд);
        МаксДлина = Макс(МаксДлина, Инд - Начало + 1);
    КонецЦикла;
    
    Возврат МаксДлина;
КонецФункции
